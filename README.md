# 🍺 ドクロ酒場

スマホ1台を回しても、みんなのスマホでも遊べる飲み会ゲーム集。2〜8人。サーバー不要の静的サイトです。

**https://warabinbin.github.io/dokuro-saloon/**

## Quick start

1. 上のURLを開く(インストール不要)。
2. 遊び方を選ぶ。
   - **1台を回して**: 名前を入れてスマホを回す。
   - **オンライン**: ホストが「部屋を作る」で出る4文字のコードを、みんなが「入る」に入力。各自のスマホに自分用の画面が出る。
3. ゲームを選ぶ(迷ったら「おまかせ」)。途中で戻るときは「← ゲーム選択に戻る」(オンラインはホストのみ)。

## ゲーム

| 種類 | ゲーム |
|---|---|
| 会話・ブラフ | 嘘つきグラス |
| 協力 | ならべ酒場 / お絵描きリレー |
| 盛り上がる | 爆弾リレー / おでこクイズ / 王様ゲーム |
| 空気・運 | 犯人は誰だ / ナンバー乾杯 / シンクロ連想 |
| その他 | ミッション / 幕間ミニゲーム / おまかせ |
| アクション | ボンバー酒場(オンライン専用・2〜8人対戦、人数でマップが広がる、アイテム6種) / [ドクロ・インベーダー](invaders/)(1台モードは結果が酒場に反映。オンラインは各自のスマホで対戦) |

## 酔いゲージ

負けてひと口飲むたびに、名前の横のジョッキが満ちていく。満タン(5杯)になると「泥酔イベント」が発動(ゲージは2に戻り、泥酔回数が付く)。免除/身代わりカードで1杯ぶん戻せる。

## 仕組み

- `index.html`(酒場)と `invaders/index.html` は、それぞれ単体で動くHTML。ビルド不要、編集してpushすればGitHub Pagesに反映される。
- オンラインは公開MQTTブローカー(wss)経由の中継。ホストがゲーム処理をして、各スマホに画面を配る。自前サーバーなし。
- 酒場とインベーダーは `localStorage`(`dk_state` / `dk_result`)で名前と結果を共有する。

## ローカルで試す

```
python -m http.server 8000   # http://localhost:8000/
```

オンラインのテストは、別のタブ(またはシークレットウィンドウ)を複数開いて同じ部屋コードで入る。

## 注意

- 通信は公開ブローカーを使うため、部屋コードを知っている人は誰でも入れる。秘密の情報は載せないこと。
- 飲酒は適量で。無理に飲ませない。
